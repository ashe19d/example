# example

Demo testing!

Built with Vexora SiteKit.

## Files
- `index.html`: the page content
- `style.css`: the styles
- `logo.svg`: the generated logo

## Edit
Change the text in `index.html` and the styles in `style.css`. The accent color is the `--site-accent` value in `index.html`.

## Publish
Open the repository's Settings, then Pages, and choose the default branch with the root folder.
